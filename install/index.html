Install ATLAS

Add ATLAS to your phone for quick access to warehouse tools.

Get started

  1. 1
    Copy the link into Safari

    Copy and paste the install link into Safari.

  2. 2
    Tap Share

    Open Safari’s Share menu.

  3. 3
    Add to Home Screen

    Choose Add to Home Screen. Turn on Open as Web App when offered, then tap Add.

  1. 1
    Open in Chrome

    Copy and paste the install link into Chrome.

  2. 2
    Choose Install

    Tap Install ATLAS below if shown. Otherwise, tap Chrome’s three-dot menu and choose Install app or Add to Home screen.

  3. 3
    Confirm installation

    Follow the prompt, then open ATLAS from your Home Screen.

Open ATLAS in your browser, or use your browser’s Install app option when available.
