Install ATLAS

Add ATLAS to your phone for quick access to warehouse tools.

Get started

  1. 1
    Tap Open ATLAS

    Tap the button below to open ATLAS. If needed, choose Open in Safari.

  2. 2
    Tap Share

    Open Safari’s Share menu.

  3. 3
    Add to Home Screen

    Choose Add to Home Screen. Turn on Open as Web App when offered, then tap Add.

  1. 1
    Open ATLAS in Chrome

    Tap Open ATLAS. If needed, open this page in Chrome.

  2. 2
    Choose Install

    Tap Install ATLAS if shown. Otherwise, open Chrome’s three-dot menu and choose Install app or Add to Home screen.

  3. 3
    Confirm installation

    Follow the prompt, then open ATLAS from your Home Screen.

  1. 1
    Open ATLAS

    Click the button below.

  2. 2
    Show the top bar

    Press Ctrl + Shift + B if it’s hidden.

  3. 3
    Save ATLAS

    Press Ctrl + D, choose Favorites bar or Bookmarks bar, then click Done.
