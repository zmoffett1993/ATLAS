ATLAS V248 — OFFICIAL COC DESKTOP SAVE AS + FILENAME ORDER

BASE VERSION
Install this small update over ATLAS V247.

WHAT CHANGED
On a supported Windows office browser, selecting DOWNLOAD OFFICIAL COC now opens the native Save As window before ATLAS retrieves the workbook.

- The Save As window starts at Desktop.
- The completed customer / IF / invoice filename is already populated.
- The file type is restricted to an Excel .xlsx workbook.
- The employee only needs to confirm the location and select Save.
- Cancelling the Save As window does not download or modify anything.

The final filename order is now:

CUSTOMER NAME IF-##### INV-#####.xlsx

Example:
NORKOL PACKAGING IF-73644 INV-56987.xlsx

The same filename generator is used by the Receiver, oversight dashboard, stored COCs, previews, resends, and newly generated official workbooks.

FALLBACK
If the browser does not support the native Save As interface, ATLAS uses the existing standard browser download behavior. No COC is lost and the workbook filename remains unchanged.

No SQL migration is required.

VERIFY AFTER GITHUB PAGES PUBLISHES
1. Wait for the GitHub Pages deployment to complete successfully.
2. Close and reopen the COC Receiver, or refresh twice so V248 activates.
3. Open any received or completed COC.
4. Select DOWNLOAD OFFICIAL COC.
5. Confirm the Windows Save As window opens at Desktop.
6. Confirm the complete customer / IF / invoice filename is already entered.
   Example: NORKOL PACKAGING IF-73644 INV-56987.xlsx
7. Select Save and confirm the .xlsx workbook appears on Desktop.
