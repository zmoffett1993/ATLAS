# ATLAS — Warehouse SKU Finder

ATLAS is a focused warehouse-navigation tool designed to help employees locate SKUs quickly, accurately, and confidently.

## Current release

**Sprint 1 — Design System & Foundation**

Included:

- Chubby Gorilla branding
- Responsive ATLAS application shell
- Live Supabase SKU search and autocomplete
- Timestamped recent searches
- Browse Aisles grid
- Simplified A–D aisle map
- Home and Browse Aisles navigation
- Supervisor access stored in the menu
