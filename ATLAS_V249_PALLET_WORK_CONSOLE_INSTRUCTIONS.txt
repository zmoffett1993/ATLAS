ATLAS V249 — SINGLE-SCREEN PALLET WORK CONSOLE

BASE VERSION
Install this small update over ATLAS V248.

WHAT CHANGED
The active pallet counting page now matches the approved four-state design board.

MAIN WORK SCREEN
- The full working console is optimized to fit on one standard iPhone screen without routine vertical scrolling.
- The global Home / Browse Aisles / Inventory / Workflows navigation is hidden only while the active pallet console is open.
- The compact pallet header continuously shows the pallet number, recorded / confirmed boxes, progress, and remaining boxes.
- Add Box is the dominant action.
- Add Lot is the second-most prominent action.
- Add SKU and Edit / Remove remain visible but secondary.
- The current SKU and active lot are repeated immediately above Add Box.
- Remove Box, Edit Lot, and Verify & Finish remain visible together.
- Verify & Finish stays disabled until recorded and confirmed pallet counts match.

SWITCH SKU
- Tap the CURRENT SKU selector to open the Switch SKU sheet.
- Every SKU on the pallet shows its recorded box count and number of lots.
- Selecting a SKU restores the most recently used lot for that SKU.
- Switching a SKU does not add, remove, or move any boxes.
- Add SKU and Edit / Remove SKUs remain available from the sheet.

SWITCH LOT
- Tap the ACTIVE LOT selector to open the Switch Lot sheet.
- Every lot for the active SKU shows its recorded box count.
- Selecting a lot changes only where the next box will be recorded.
- Add New Lot remains available from the sheet.

EXISTING LOT DETECTED
- When a scanned or manually confirmed lot already exists for the selected SKU, ATLAS does not create a duplicate row.
- ATLAS shows the existing SKU, lot, current quantity, and next box number.
- SWITCH & ADD BOX selects the existing lot and records the scanned box in one protected action.
- CANCEL leaves all counts unchanged.

PRESERVED FROM V248
- Official COC downloads still use the native Save As window when supported.
- Save As still starts at Desktop.
- Official filenames remain CUSTOMER NAME IF-##### INV-#####.xlsx.
- The Office COC Receiver and pairing remain unchanged.
